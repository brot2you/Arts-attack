ARTS ATTACK! — POP ART ACADEMY — V1
===================================

INSTALLATION SUR GITHUB PAGES
1. Ouvrir votre dépôt GitHub Arts Attack! (ou en créer un).
2. Décompresser le ZIP.
3. Mettre À LA RACINE du dépôt le fichier index.html, style.css, app.js et le dossier assets.
4. Dans Settings > Pages, sélectionner Deploy from a branch, branche main, dossier /(root).
5. Ouvrir l’URL GitHub Pages du dépôt. Un délai de déploiement est possible.

IMPORTANT : faites une sauvegarde du dépôt existant avant de remplacer des fichiers.
N'uploadez pas le dossier Arts-Attack-V1 en tant que sous-dossier : déposez son CONTENU à la racine.

FONCTIONNALITÉS V1
- Accueil responsive avec décor, personnage et logo indépendants
- Trois grandes rubriques officielles avec images distinctes
- Navigation Missions / Atelier / Galerie / Carnet
- Trois courtes missions avec choix et réflexion personnelle
- Sauvegarde locale des réponses dans le navigateur (localStorage)
- Exploration des neuf notions plastiques
- Galerie de démonstration

LIMITES
- Pas de comptes élèves ni de synchronisation entre appareils
- La galerie contient des illustrations de l’application, pas encore de cartels d’œuvres de référence
- Les missions V1 sont de courts prototypes : ateliers artistiques complets à développer
- Les points valorisent la participation, ne constituent pas une note scolaire
- Pas de mise en ligne automatique : dépôt manuel sur GitHub nécessaire
